## 📌 О проекте

Вводите список городов — сервис геокодирует их, **сам определяет оптимальный порядок объезда**
(а не просто едет в том порядке, в котором вы их напечатали), считает расстояние по
дуге большого круга, **предсказывает удобный транспорт нейросетью, обученной с нуля**,
показывает маршрут на **интерактивной карте** и даёт **AI-совет по поездке**
(привалы, ночёвки, погода) от LLM.

Это вторая, полностью переработанная версия исходного учебного скрипта: вместо
одного процедурного файла — сервисы с чёткой ответственностью, вместо расчёта в
порядке ввода — эвристика решения задачи коммивояжёра, вместо вручную подобранных
весов — нейросеть (MLP) с backpropagation, обученная градиентным спуском на датасете.

## ✨ Возможности

### 🧠 ML / AI

- 🧠 **Нейросеть (MLP) с backpropagation, написанным с нуля** — скрытый слой
  (tanh) + softmax-выход, прямой и обратный проход на чистом PHP, без
  sklearn/tensorflow. Обучается и честно сравнивается с линейным
  baseline-классификатором (`bin/train_model.php` печатает обе точности) —
  см. подробный разбор формул и матриц весов в `docs/neural_net.md`
- 📐 **Строгая оценка модели** — confusion matrix, precision/recall/F1 по
  каждому классу (не только accuracy — она маскирует перекосы на
  несбалансированных классах) и 5-fold кросс-валидация вместо одного
  случайного train/val сплита (`App\ML\ModelEvaluator`)
- 🤖 **AI-ассистент поездки** — после расчёта маршрута LLM (Anthropic/OpenAI,
  при наличии ключа API) генерирует человеческий комментарий: где сделать
  привал, нужна ли ночёвка на длинном перегоне, стоит ли обратить внимание на
  погоду. Без ключа API работает офлайн-fallback по понятным правилам — честно
  помечено в интерфейсе, какой вариант сработал
- 📊 **Интерактивная карта решений модели** — Chart.js визуализация того, как
  классификатор делит пространство «дистанция × число точек» на walk/car/bus,
  с переключателем MLP ⇄ softmax для наглядного сравнения границ
- 📅 **AI-планировщик поездки по дням (K-Means)** — если маршрут длинный,
  алгоритм K-Means (метод Ллойда, с нуля на PHP) сам делит его на
  сбалансированные по километражу дни вождения, не нарушая порядок городов.
  В отличие от MLP/Softmax это **обучение без учителя** (unsupervised) —
  принципиально другая задача ML, без единого размеченного примера
  (`App\ML\KMeansDaySplitter`, `api/day_plan.php`)

### 🗺️ Геоданные и планирование

- 📍 **Геокодирование** городов через OpenStreetMap Nominatim (с диск-кэшем и
  соблюдением лимита запросов API)
- 🧭 **Оптимизация порядка точек** — эвристика Nearest Neighbor + локальный поиск
  2-opt (классическая связка для практических TSP-задач)
- 🛣️ **Реальный маршрут по дорогам** через OSRM — не прямые линии между
  городами, а настоящая трасса с изгибами; с честным откатом на дистанцию
  «по воздуху», если сервис маршрутизации недоступен
- ⏱️ **Оценка времени в пути** — точное время от OSRM для автомобиля,
  приблизительное (по средней скорости) для пешей/общественной поездки
- ⛽ **Точки интереса рядом с маршрутом** (АЗС, кафе, рестораны, отели) через
  бесплатный Overpass API (OpenStreetMap) — "умные остановки" на длинных
  маршрутах, без ключа API
- 🌦️ **Погода по маршруту** через Open-Meteo (без ключа) — предупреждения о
  сильном дожде, жаре, морозе или грозе прямо у каждой точки маршрута
- 🗺️ **Интерактивная карта** маршрута на Leaflet.js (маркеры + реальная
  геометрия пути, без API-ключа)
- 🔗 **Ссылка-шеринг маршрута без базы данных** — весь маршрут кодируется
  прямо в URL, получатель открывает ссылку и сразу видит расчёт
- 🔗 Готовые ссылки на Google Maps и Яндекс.Карты
- 💰 **Оценка стоимости поездки** — топливо для авто (расход × дистанция ×
  цена литра) или примерная цена билета для общественного транспорта, с
  настраиваемыми параметрами прямо в интерфейсе
- 📲 **PWA** — сайт можно установить на телефон как приложение (манифест +
  service worker с офлайн-кэшем оболочки интерфейса)
- 🏙️ **Автоподсказки городов** при вводе — живой поиск через Nominatim,
  можно листать клавиатурой (стрелки, Enter, Esc)
- 🌐 **Полная локализация интерфейса — 🇷🇺 русский и 🇬🇧 английский** —
  переключатель языка в один клик, весь UI (включая подписи, кнопки,
  подсказки и известные ошибки сервера по `error_code`) переводится на лету
  без перезагрузки страницы; выбранный язык сохраняется между визитами
  (`localStorage`, см. `public/assets/js/i18n.js`)
- ⚡ Расчёт без перезагрузки страницы (fetch → JSON API)
- 📊 **A/B-тест MLP vs Softmax в реальном времени** — каждому посетителю
  случайно (50/50) назначается модель на весь визит; после расчёта маршрута
  можно отметить 👍/👎, угадала ли она — статистика по обеим моделям копится
  в `var/ab_stats.json` и видна прямо в интерфейсе (карта решений → A/B-тест)
- ✅ 132 теста на ключевую логику — из них 106 unit-тестов (классы напрямую,
  с поддельными зависимостями) и 26 HTTP-интеграционных (см. ниже)

### ⚙️ Инженерная зрелость

- 🚦 **Rate limiting (token bucket, с нуля)** — свой алгоритм ограничения
  частоты запросов без Redis: непрерывное пополнение "токенов", а не наивный
  fixed-window счётчик (у которого есть классическая уязвимость на границе
  окна). Защищает бесплатные Nominatim/Overpass/Open-Meteo от шквала
  запросов и не даёт заспамить общие demo-эндпоинты (`learn.php`,
  `feedback.php`) — см. `App\Http\RateLimiter`
- 🧪 **HTTP-интеграционные тесты** — отдельно от unit-тестов (которые бьют по
  классам напрямую с фейковыми зависимостями), `tests/Http/` поднимает
  настоящий `php -S` и стучится по HTTP в реальные `api/*.php`: проверяет
  разбор `$_POST`/`$_GET`, HTTP-коды (405/422/429), `error_code` в JSON и
  поведение rate limiter'а на живом запросе — то, что unit-тесты в принципе
  не видят
- 🤖 **CI (GitHub Actions, [`.github/workflows/ci.yml`](.github/workflows/ci.yml))** —
  на каждый push/PR: `php -l` по всем файлам, полный прогон тестов на
  PHP 8.1/8.2/8.3 (матрица), smoke-тест поднятия сайта на встроенном
  сервере, `composer audit`

## 🚀 Быстрый старт

Проекту **не нужна база данных** и не обязателен Composer — только PHP.
Обученная модель уже включена в репозиторий (`src/ML/model_weights.json`),
переобучать её перед первым запуском не нужно.

```bash
# 1. Запустите встроенный сервер PHP (документ-рут — папка public/)
php -S localhost:8000 -t public

# 2. Откройте в браузере
http://localhost:8000
```

Хотите переобучить модель сами (например, после правок в `Dataset.php`)?

```bash
php bin/train_model.php
```

AI-ассистент поездки и точки интереса/погода работают "из коробки" без какой-либо
настройки (офлайн-fallback для AI-текста, бесплатные Overpass/Open-Meteo API для
геоданных). Чтобы AI-комментарий генерировался настоящей LLM, а не шаблоном,
задайте переменную окружения перед запуском сервера:

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # или OPENAI_API_KEY=sk-...
php -S localhost:8000 -t public
```

Как развернуть на XAMPP (без терминала) и что конкретно нужно установить — в
[`docs/setup_guide.md`](docs/setup_guide.md).

### 🐳 Или через Docker (PHP на хосте вообще не нужен)

```bash
cp .env.example .env      # ключи API опциональны, см. комментарии в файле
chmod -R 777 var          # см. docs/setup_guide.md — почему это нужно для bind-mount
docker compose up --build
```

Откройте `http://localhost:8080`. Тот же образ подходит и для деплоя на
VPS — подробнее в [`docs/setup_guide.md`](docs/setup_guide.md).

## 🛠 Стек технологий

| Слой | Технологии |
|---|---|
| Backend | PHP 8.1+, ООП, PSR-4 (composer.json + собственный автозагрузчик как фолбэк) |
| Геокодирование | OpenStreetMap Nominatim API, cURL, файловый кэш |
| Маршрутизация | OSRM (реальные дороги) с откатом на Haversine + Nearest Neighbor/2-opt |
| Machine Learning | MLP (скрытый слой + backprop с нуля) и Softmax-регрессия — обучение градиентным спуском, кросс-энтропийная потеря; K-Means (метод Ллойда, с нуля) — unsupervised-кластеризация маршрута по дням |
| AI-ассистент | Anthropic Messages API / OpenAI Chat Completions (опционально), офлайн rule-based fallback |
| Геоданные | Overpass API (точки интереса), Open-Meteo (погода) — оба без ключа |
| Frontend | Vanilla JS (fetch API), Leaflet.js, Chart.js, CSS |
| Тестирование | Собственный лёгкий test-runner (без внешних зависимостей); HTTP-интеграционные тесты через `php -S` |
| Rate limiting | Token bucket с нуля (`App\Http\RateLimiter`), файловое хранилище с `flock` |
| CI/CD | GitHub Actions — lint + тесты на PHP 8.1/8.2/8.3, smoke-тест сервера, `composer audit` |
| Деплой | Docker + docker-compose (образ на `php:8.3-apache`), либо обычный shared-хостинг/XAMPP без Docker вообще |

## 🧪 Тесты

```bash
php tests/run.php
```

Покрыты: расчёт расстояния (Haversine), оптимизация порядка точек (TSP-эвристика),
обучение и точность MLP- и softmax-классификаторов, строгая оценка (confusion matrix,
precision/recall/F1, k-fold кросс-валидация), unsupervised-кластеризация маршрута по
дням (K-Means: сбалансированность, монотонность порядка, детерминированность),
rate limiter (token bucket: разные клиенты, пополнение во времени, fail-open при
сбое диска), оценка времени в пути, оценка стоимости поездки, полная интеграция
`RoutePlanner`, и HTTP-интеграционные тесты через настоящий `php -S` (405/422/429,
`error_code`, day-plan/decision-boundary/explain/assistant "живьём") — 132 теста
в сумме. Гоняются автоматически в CI на каждый push (см. `.github/workflows/ci.yml`).

## 🧭 Известные ограничения

- Оптимизация маршрута — эвристика (Nearest Neighbor + 2-opt), не гарантирует
  математически точный оптимум, но для 3–20 точек даёт результат, очень близкий
  к нему, за миллисекунды.
- Точное время в пути от OSRM доступно только для автомобиля — публичный
  демо-сервер OSRM поддерживает лишь профиль `driving`. Для пешей/общественной
  поездки время — приблизительная оценка по средней скорости.
- OSRM — бесплатный публичный демо-сервер без SLA; при его недоступности
  приложение честно откатывается на дистанцию «по воздуху» (это видно в
  интерфейсе пометкой источника данных).
- ML-модель обучена на **синтетическом** датасете (нет накопленной статистики
  реальных пользователей) — см. честное объяснение в `docs/neural_net.md`.
- MLP (нейросеть) не даёт драматического прироста точности над линейным
  softmax-baseline на этих двух признаках — разница в пределах статистического
  шума на валидационной выборке. Честно разобрано (с цифрами по нескольким
  seed) в `docs/neural_net.md`: ценность MLP здесь — в архитектуре и заделе
  на будущее, а не в текущем скачке accuracy.
- AI-совет по поездке без настроенного ключа API (`ANTHROPIC_API_KEY` /
  `OPENAI_API_KEY`) — это офлайн rule-based текст, а не настоящий вывод LLM;
  интерфейс честно это помечает.
- Overpass API (точки интереса) и Open-Meteo (погода) — бесплатные публичные
  сервисы без SLA и с разумными лимитами по частоте запросов; при
  недоступности приложение просто не показывает эти данные, не ломая расчёт
  основного маршрута.
- История маршрутов не сохраняется (кроме шеринга через ссылку) — раздумья на
  будущее: SQLite для истории, учётные записи, экспорт в GPX.
- Стоимость поездки — грубая прикидка (см. `src/Routing/CostEstimator.php`),
  а не точный расчёт: реальные цены на топливо/билеты сильно зависят от
  региона и перевозчика. Валюта фиксирована (₽), но параметры расчёта
  (цена топлива, расход, цена билета) можно поменять прямо в интерфейсе.
- Rate limiter определяет клиента по IP (с опциональным доверием
  `X-Forwarded-For`) — этого достаточно для одного сервера, но при деплое
  за балансировщиком/CDN значение стоит проверить/настроить под конкретную
  инфраструктуру (см. докблок `App\Http\ClientIdentity`). Состояние
  лимитера — локальный файл на диске, не шарится между несколькими
  серверами при горизонтальном масштабировании.
- Автоподсказки городов и сам расчёт маршрута требуют доступа в интернет
  (Nominatim/OSRM) — без сети форма подскажет об этом, но не упадёт.
- Локализация (RU/EN) переводит интерфейс полностью, но сообщения об ошибках
  сервера переводятся только для известных `error_code`; нестандартные ошибки
  показываются как есть (на русском).
- План по дням (K-Means) балансирует дни **по километражу перегонов**, а не
  по факту наличия жилья/ночёвки в конкретном городе — это подсказка «где
  примерно заканчивается разумный день вождения», а не бронирование отеля.
  Кластеризация всегда учитывает исходный порядок точек маршрута (день не
  может «прыгнуть» назад) — подробнее см. докблок `App\ML\KMeansDaySplitter`.
