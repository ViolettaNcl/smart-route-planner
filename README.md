# Route AI Calculator

Веб‑калькулятор маршрутов на PHP: по списку городов строит маршрут, считает суммарную дистанцию и с помощью простой «нейросети» предлагает подходящий тип транспорта.

Проект не использует базу данных, все вычисления выполняются в памяти в рамках одного HTTP‑запроса.

## Структура проекта

```text
project-root/
├── index.php          # UI: форма ввода и вывод результата
├── route_logic.php    # Бизнес-логика: геокодирование, расстояние, нейросеть
├── route.css          # Оформление интерфейса
└── docs/              # Документация
    ├── architecture.md
    ├── neural_net.md
    ├── business_analysis.md
    └── setup_guide.md
```

Основной вход в приложение — файл `index.php`, который подключает `route_logic.php` и рендерит HTML‑интерфейс.

## Быстрый запуск

1. Скопировать проект в папку веб‑сервера, например `C:/xampp/htdocs/site1/Route`.
2. Убедиться, что Apache и PHP запущены (например, через XAMPP).
3. Открыть в браузере `http://localhost/site1/Route/index.php` или, при настроенном виртуальном хосте, `http://site1.local/`.
4. Ввести города через `;` и нажать «Рассчитать маршрут».

Сервис обращается к OpenStreetMap Nominatim для геокодирования, считает расстояние по формуле гаверсинусов и предлагает тип транспорта.

## Используемые технологии

| Слой            | Технология                        |
|-----------------|-----------------------------------|
| Веб‑сервер      | Apache (например, из XAMPP)      |
| Язык backend    | PHP 8.x                          |
| Внешний сервис  | OpenStreetMap Nominatim (геокод) |
| Frontend        | Чистый HTML + CSS (`route.css`)  |
| Хранилище       | Без базы данных                  |

## Основной сценарий использования

1. Пользователь вводит список городов (через `;`).
2. Приложение геокодирует каждый город в координаты.
3. На основе координат вычисляется суммарная длина маршрута.
4. Простая модель‑классификатор по расстоянию и количеству точек выбирает режим передвижения.
5. Генерируются ссылки для построения маршрута в Google Maps и Яндекс.Картах.
