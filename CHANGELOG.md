## [Unreleased]

### Added
- Отказоустойчивая маршрутизация: упорядоченная цепочка OSRM-compatible
  провайдеров, файловый кэш успешных дорожных маршрутов и stale-on-error
  восстановление при кратком внешнем сбое.
- Canonical URL, `robots.txt` и `sitemap.xml` автоматически используют
  `APP_PUBLIC_URL` или production-domain Vercel, поэтому подключение своего
  домена больше не требует правки исходников.
- Map-first интерфейс: карта занимает около 70% desktop-сцены, отображается
  ещё до первого расчёта и использует бесплатные векторные данные OpenFreeMap
  без регистрации и API-ключа.
- Переключаемые без перезагрузки режимы 2D/3D: объёмные здания, рельеф и
  hillshade Mapterhorn, globe-проекция, фирменная атмосфера и освещение.
- Честная сцена расчёта по фактическим состояниям: запрос маршрута, движение
  камеры, поэтапная прорисовка реальной геометрии, маркеры и итоговая сводка.
- Статический SVG-fallback строится из координат ответа API, если WebGL,
  основной стиль, terrain или 3D-слои недоступны; расчёт маршрута при этом
  остаётся полностью рабочим.
- Доступная клавиатурная навигация вкладок, ARIA live-регионы статусов и
  ошибок, адаптивная маршрутная timeline и поддержка `prefers-reduced-motion`.
- Сам базовый canvas карты теперь визуально отличается от прежнего: тёмный
  стиль OpenFreeMap Fiord и светлый Liberty, отдельный индикатор активного
  стиля и метрическая шкала MapLibre.
- Production-конфигурация Vercel Functions с PHP 8.3 front controller и новым
  live demo URL.
- Интеграция Vercel AI Gateway: на Vercel используется автоматически
  обновляемый OIDC-токен, а прямые Anthropic/OpenAI-ключи остаются резервом.
- `App\Support\RuntimeStorage` переносит изменяемые данные в доступное для
  записи хранилище (`/tmp` в Vercel Functions, `var/` локально и в Docker).
- Полная перерисовка интерфейса под desktop: карта и форма в одну строку
  сверху, результат — полноширинная приборная панель с вкладками (города /
  модель / AI-совет / доп. / поделиться) вместо одной длинной колонки.
- Светлая и тёмная тема (переключатель в шапке, сохраняется в
  `localStorage`); карта и график границы решений модели перекрашиваются
  вместе с интерфейсом.
- Фирменный логотип и favicon (SVG + PNG всех нужных размеров, включая
  maskable-иконку для PWA).
- Градиентный (фиолетовый → cyan → янтарный) трек маршрута на карте,
  отдельно оформленные маркеры старта/финиша с пульсацией.
- Двуязычная документация: `README.md`/`README.ru.md` и англ. версии всех
  файлов в `docs/`.
- `api/health.php` — health-check эндпоинт для аптайм-мониторинга и
  `HEALTHCHECK` в Docker.
- Статический анализ (PHPStan, уровень 6, 0 ошибок) и автоформатирование
  кода (PHP-CS-Fixer, PSR-12) — оба шага теперь часть CI.
- `.github/dependabot.yml` — еженедельные проверки обновлений для Composer,
  GitHub Actions и Docker-образа.
- `.github/workflows/docker-publish.yml` — автосборка и публикация образа в
  GitHub Container Registry на каждый push в `main`.
- Простой файловый логгер (`App\Support\Logger`) — фиксирует в `var/app.log`
  каждое fallback-переключение (OSRM → Haversine, LLM → rule-based текст),
  которое раньше было видно только в ответе API, но не в логах сервера.
- `.gitattributes` и `.editorconfig` — единообразные окончания строк и
  форматирование независимо от ОС/IDE разработчика.

### Fixed
- Компактная мобильная вкладка редактора получила фирменный маршрутный знак,
  двухуровневую подпись с действием «Рассчитать маршрут», градиентный акцент,
  улучшенные отступы и заметную кнопку раскрытия в светлой и тёмной темах.
- Мобильный редактор маршрута теперь открывается одним нажатием сразу на
  весь экран и закрывается до одной компактной вкладки; содержимое формы
  полностью скрыто в закрытом состоянии, фон не прокручивается, а высота
  учитывает динамический viewport и safe-area телефона.
- Мобильная подсказка выбора точки больше не наследует полноэкранные размеры
  затемняющей маски карты и не превращается в огромную тёмную «капсулу»;
  первая и вторая выбранные точки получают компактную подсказку и маркеры.
- Устранена гонка MapLibre после включения Fiord/terrain: сцена маршрута
  больше не зависает на статусе «Настраиваю обзор маршрута…», а ограниченно
  ждёт доступности style JSON и гарантированно переходит к SVG-fallback при
  ошибке. Добавлен отдельный frontend regression-тест этого сценария.
- Версионированные CSS/JS и network-first навигация service worker устраняют
  ситуацию, когда установленное PWA продолжало показывать старый интерфейс
  после успешного Vercel deployment.
- Убран водяной знак `API KEY REQUIRED` от прежнего raster-провайдера карты;
  слой больше не зависит от коммерческого токена.
- Vercel Hobby build больше не превышает лимит в 12 Serverless Functions:
  все HTTP-эндпоинты обслуживает один PHP front controller.
- Несовпадающий PHPDoc-тип константы `WEATHER_CODES` в `OpenMeteoClient`.
- Пропущенный заголовок раздела в `docs/neural_net.md` (список ограничений
  модели шёл без заголовка).
- Устаревшая инструкция в `docs/setup_guide.md`, противоречившая тексту
  тремя абзацами выше (веса модели уже есть в репозитории, переобучать
  перед первым запуском не нужно).
- `ui.js` и `ml_boundary.js` отсутствовали в списке офлайн-кэша PWA
  (`service-worker.js`) — после установки приложения офлайн-режим открывался
  без темы/вкладок и без графика модели.

## [1.1.0] — AI и объяснимость модели

### Added
- AI-ассистент поездки: LLM (Anthropic/OpenAI) генерирует текстовый совет по
  маршруту, с честным rule-based fallback без ключа API.
- Интерактивная визуализация decision boundary модели (Chart.js) с
  переключателем MLP ⇄ Softmax.
- Разбор конкретного предсказания модели ("почему такой транспорт") —
  `api/explain.php`.
- Живой A/B-тест MLP vs Softmax на реальных визитах + возможность
  дообучить модель на лету одним примером и откатить веса обратно.
- Нейросеть (MLP) с backpropagation, реализованным с нуля — как
  архитектурная альтернатива линейному `SoftmaxClassifier`, с честным
  сравнением точности между ними.
- Строгая оценка модели: confusion matrix, precision/recall/F1 по классам,
  k-fold кросс-валидация (`App\ML\ModelEvaluator`).
- AI-планировщик поездки по дням — unsupervised K-Means с нуля
  (`App\ML\KMeansDaySplitter`).
- Точки интереса вдоль маршрута (Overpass API) и погода в каждой точке
  (Open-Meteo).
- Локализация интерфейса (RU/EN) и PWA (установка на телефон, офлайн-кэш).

## [1.0.0] — Первый релиз слоистой архитектуры

### Added
- Полный переход от процедурного скрипта с захардкоженными весами к
  слоистому PHP-приложению с внедрением зависимостей.
- Оптимизация порядка точек маршрута: Nearest Neighbor + 2-opt вместо
  «ехать в порядке ввода».
- Обученный классификатор транспорта (`SoftmaxClassifier`) вместо вручную
  подобранных весов — градиентный спуск на кросс-энтропийной функции
  потерь.
- Реальная маршрутизация по дорогам через OSRM с честным откатом на
  дистанцию по прямой при недоступности сервиса.
- Ссылка-шеринг маршрута без базы данных.
- Оценка стоимости поездки и выбросов CO2.
- Rate limiter (token bucket) с нуля для защиты бесплатных лимитов внешних
  API.
- 132 автотеста (unit + HTTP-интеграционные) и CI на трёх версиях PHP.
- Docker/docker-compose для локального запуска и деплоя.
